## Q1〔v1.2 差分・Delta 1〕我沒讀過什麼古文，《易經》看得懂嗎？

改動一處：「這門學問的本性,不是深奧,是簡易。」→「**這門學問把簡易擺在前頭,不拿深奧當門檻。**」（採已核准修正：本體絕對句→可證的門檻句——簡易確在繫辭首章之首、「擺在前頭」可證；誠實承認深、只卸門檻）。保留第一組之《繫辭》歸屬（「這門學問,自己先把話說了」，不稱「易經自己說」、不混稱經傳）與白話對齊（「平易,人才懂得了;簡單,人才跟得上」，只譯所引八字）。

```
【問】我沒讀過什麼古文,《易經》看得懂嗎?
【老易說】看得懂。這門學問,自己先把話說了。繫辭寫著:「易則易知,簡則易從。」平易,人才懂得了;簡單,人才跟得上。這門學問把簡易擺在前頭,不拿深奧當門檻。古文那一層,書房替您講淺;道理那一層,您做過事,本來就懂。先讀,讀不懂的,再問。
```

## Q12〔v1.2 差分・Delta 4〕卜到不好的卦怎麼辦？我會不會越看越擔心？

以第一組 v1.1 為底，改三處：①移除結果保證「也說了怎麼走能過」——卦寫了過法是文本事實，但「能過」是介面替結果背書，拔除；②「為的是繞得過去」→「為的是看路」——路標的功能收在「指險、看路」，過不過不掛保證；③「艱貞無咎」入文，**僅作經文條件錨**：緊跟泰九三、白話明標「難處守得正,才談無咎;是條件,不是包票」——不得解讀為必然過關。書房閱讀框（「但在書房,這些字讀的是條件」）與誠實拍照舊；全文無「從來／一律／都是」、無「能過／繞得過去／就不會怕」型承諾。
字數實算（既有口徑）：**含標點 150／純漢字 119**——兩口徑皆落 spec 100–150 帶內（原檔 12 題實測：含標點 91–161、純漢字 75–134）。

```
【問】卜到不好的卦怎麼辦?我會不會越看越擔心?
【老易說】先說老實話:卦辭裡,是有吉有凶,老易不瞞您。但在書房,這些字讀的是條件:處在這個時位,怎麼走則吉,怎麼走則凶——不是落在誰頭上的判決。泰卦九三說:「無平不陂,無往不復。」緊接著:「艱貞無咎。」難處守得正,才談無咎;是條件,不是包票。兇的卦,是提醒:此處有險。把卦當路標:指出坑,不為嚇人,為的是看路。
```

（「艱貞無咎」逐字已核 yaoci JSON——泰九三「無往不復」緊接四字。政策點不變：本題仍偏離 S165 spec「卦無好壞」姿態字面、保留其卸懼意圖——Owner 對本稿點頭＝對此轉向點頭。）
