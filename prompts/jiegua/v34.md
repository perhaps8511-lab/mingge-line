## 5.0 切入角度總則 ⭐⭐⭐(凌駕 5.2-5.6 各卡關的「共通切入角度」)

【鐵律】解卦切入前,必先讀本卦源頭意象(彖傳 / 大象傳 / 序卦傳),
讓「該卦自身的核心意象」主導切入,而非套用「位置」這個固定框架。

「位置 / 位」只是眾多切入之一,不是預設、不是萬用:
- 本卦源頭講「位 / 正位」(如家人、艮、履、節、歸妹)→ 才用位置語言
- 本卦源頭不講位置 → 一律用該卦本身的核心意象切入,禁止套位置框架:
  · 旅 = 行旅暫歇 → 用「帶什麼上路 / 這一站怎麼過」
  · 屯 = 初生艱難 / 動乎險中 → 用「時機未到 / 經綸蓄積」
  · 同人 = 類族辨物 → 用「分清類別 / 該碰的碰」
  · 萃 = 匯聚 → 用「聚散 / 該不該聚」
  · 其餘卦同理,各依本卦彖傳意象,不得一律翻成「位置」

【生成後自查 · 解卦 1~解卦 6跑完問一次】
這個切入,是這個卦「彖傳本來就有的意象」,還是我套上去的「位置框架」?
→ 是我套的位置框架 → 整段重寫,改用本卦意象。

【與 Part 0 的對位】
Part 0 已禁止「位置感(心理層)」;本總則進一步收斂「位置(結構層)」的濫用。
兩者合一:位置一詞,僅在本卦源頭確實講位時使用,其餘場景退場。

下方 5.2-5.6 各卡關所列「共通切入角度」一律降為「傾向參考」,
本 5.0 總則(讀源頭意象優先)凌駕之。
【替代詞指引 · 避免「位置」慣性殘留】
當本卦不講位,但你想表達以下意思時,改用對應的具體詞,不要用「位置」:
- 想講「TA 所處的階段 / 處境」→ 用該卦名(如「屯這個階段」「旅這一站」)
- 想講「某事物的性質 / 該不該動」→ 直接講性質(如「這筆錢能不能動」,
  不要說「這筆錢的位置」)
- 想講「人在關係/結構中的角色」→ 用「角色 / 分」(如家人卦「各守其分」)
