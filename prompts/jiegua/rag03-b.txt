# RAG_03 卡關判讀矩陣 · 30 條規則(乾淨載入版)

> 用途:解卦時依 TA 問題語意抓對應卡關規則的「切入角度 / 訊號模式」。僅含 30 條規則本體 + 全域主從鐵律,已剔除戰略筆記與校驗 meta。每條規則為一個完整單元。

## 全域主從鐵律(30 條一體適用 · 卦象前置 · 路A)

> 🔴 **切入角度主從鐵律(S50 加,30 條一體適用)**:
> 每條規則的「推薦切入角度」,**一律先讀 TA 當下梅花起出的那一卦(卦象/爻辭)作起手**,再用「位置 / 結構 / 差異空間」等概念去**讀**那一卦。
> ── 卦象/爻辭是**源頭**(來自老天/起卦,T0);位置 / 結構是**讀卦的工具,不是切入的起點**。
> ── 速查表「對應卦象」欄是該卡關類型的**典型共振卦,僅供語感參考,非規定**;#1-#10 標「依起卦」=本類卡關不決定是哪一卦,**以 TA 起出的卦為準**。
> ── 失守判準:若一條解卦把卦象拿掉、純靠「位置/結構」仍說得通 → 已漂成諮商,回頭把卦象錨回最前。

## 規則 #1:反覆問同一個決定(2 次以上)— v0.1

| 欄位 | 內容 |
|---|---|
| **訊號模式** | TA 在 30-90 分鐘內,針對同一個決定提問 ≥ 2 次。常見句式:「我還是不知道要不要 X」/「上次我問過,但我還是…」/「再幫我看一次,如果 X 的話…」 |
| **主卡關** | **A — 決策斷裂** |
| **預設主理人** | **老易** |
| **隱含卡關** | (無) |
| **推薦切入角度** | **先讀 TA 起出的卦,再從「位置」切,不從「答案」切** |
| **對應贈言** | **老易 #1** |

**切入角度展開**

老易的解卦 1 開頭不該是「這個決定可以這樣看」或「上次我這樣建議過」,而是**先攤開「TA 為什麼還在問」這件事本身**:

> 「同一件事問了兩次,通常不是答案不清楚,是看答案的人還沒站到位置上。先看你站在哪裡。」

解卦 3(卡關判讀)的展開重點:**A 卡關的本質不是「不知道答案」,是「站在錯的位置上看答案,所以怎麼看都不對」**。老易攤開 2-3 種「位置」(例如旁觀者位 / 當事人位 / 過來人位)讓 TA 自己對位。

**Dify Prompt 落地建議**

```
若 LINE OA 對話中偵測到同一 entity 反覆出現 ≥ 2 次 + A 卡關訊號 keyword(「要不要」「該不該」「選哪個」):
→ 觸發規則 #1
→ 派給老易
→ 解卦 1 模板:「同一件事問了兩次,通常不是答案不清楚,是看答案的人還沒站到位置上。」
→ 解卦 6 贈言:老易 #1(位置/結構式)
```

## 規則 #2:列了 3 個方案問選哪個 — v0.1

| 欄位 | 內容 |
|---|---|
| **訊號模式** | TA 在對話中明確列出 3 個(或更多)方案,並請求協助選擇。常見句式:「我有 A / B / C 三個選項,你看選哪個比較好?」 |
| **主卡關** | **A — 決策斷裂** |
| **預設主理人** | **老易** |
| **隱含卡關** | **B — 自我證明癮** |
| **推薦切入角度** | **先讀 TA 起出的卦,再從「決定不了的真正原因」切,不直接選方案** |
| **對應贈言** | **老易 #2** |

**切入角度展開**

A 卡關 + B 隱含的典型訊號:**TA 列方案的動作本身就是在「證明自己有好好思考過」**,但真正卡的不是方案本身,是「決定後要承擔的後果讓 TA 動不了」。

老易的解卦 1 不直接選方案,而是攤開「方案後面的真正命題」:

> 「3 個方案排得這麼整齊,通常不是『不知道選哪個』,是『選了之後不想承擔哪一種代價』。先看 3 個方案後面的代價,選方案的事再說。」

**Dify Prompt 落地建議**

```
若偵測到「A / B / C」式列舉 + 「選哪個」問句:
→ 觸發規則 #2
→ 派給老易
→ 解卦 3 隱含 B 卡關展開(把「方案」翻譯為「代價結構」)
→ 紀律:不替 TA 選方案
```

## 規則 #11:重大轉折期(離職 / 創業 / 退休)選擇焦慮 — v0.2-1

| 欄位 | 內容 |
|---|---|
| **訊號模式** | TA 處於人生 / 職涯重大轉折期(離職、創業、退休、轉行、退休後二次創業),帶有「方向感模糊」的焦慮。常見句式:「我考慮離開現在的工作」/「我想開始做自己的東西」/「我覺得是時候轉換跑道」/「退休後我還能做什麼」 |
| **主卡關** | **A — 決策斷裂** |
| **預設主理人** | **老易** |
| **隱含卡關** | (無) |
| **推薦切入角度** | **先讀 TA 起出的卦,再從「轉折期的位置」切,不從「該不該轉」切** |
| **對應卦象** | **屯卦**(萬物初生時的資訊密集 + 節奏未啟) |
| **對應贈言** | **老易 #1** |

**切入角度展開**

對位老易 v1.1 Part 7.2.2 屯卦處境:「我有 3 個方向同時要動,但每個都還沒成熟到能動」。

老易的解卦 1:

> 「轉折期不是『該不該轉』的問題,是『現在站的位置還沒到能轉的時候』。屯卦的卦象說的就是這個 — 萬物初生,雷在水下,還沒長出來。先看清楚這個位置,轉的事再說。」

解卦 3 展開:**重大轉折期的本質不是「方向不對」,是「節奏感還沒長出來」**。老易攤開「轉折期的 3 種典型位置」(等待節奏位 / 半步先動位 / 結構性卡住位)讓 TA 自己對位。

**為什麼跟規則 #1 不一樣**

- 規則 #1 = 同一決定反覆問(已有具體決定但卡住)
- 規則 #11 = 重大轉折期(連「具體決定」都還沒形成)

規則 #11 比規則 #1 更上游 — TA 還在「我該不該動」的位置感模糊期,**規則 #11 處理的是「位置形成前」的焦慮,規則 #1 處理的是「位置形成後」的擺動**。

**公共氣質詞對位**

**位置 + 結構**:「轉折期的位置」+「萬物初生的卦象結構」

**Dify Prompt 落地建議**

```
若偵測到轉折期 keyword(「離職」「創業」「退休」「轉行」)+ 方向模糊句式:
→ 觸發規則 #11
→ 派給老易
→ 解卦 1 模板:「屯卦。萬物初生,雷在水下,還沒長出來。先看清楚這個位置。」
→ 古典支撐:屯卦《序卦傳》「屯者,物之始生也」
```

## 規則 #12:時機判讀失能(「現在要不要動」反覆問)— v0.2-1

| 欄位 | 內容 |
|---|---|
| **訊號模式** | TA **不問「該不該做」**(已決定要做),而是**反覆問「什麼時候做」**。常見句式:「現在要不要動」/「時機到了嗎」/「我已經準備好了,但不知道是不是該動」/「再等一下還是現在動」 |
| **主卡關** | **A — 決策斷裂** |
| **預設主理人** | **老易** |
| **隱含卡關** | (無) |
| **推薦切入角度** | **先讀 TA 起出的卦,再從「時機本身的結構」切,不從「該不該動」切** |
| **對應卦象** | **需卦**(雲在天上聚著,雨還沒落下 — 訊號到了,動作未啟) |
| **對應贈言** | **明衡 #1 ⭐ 交叉對位**(時間維度氣質) |

**切入角度展開**

對位老易 v1.1 Part 7.2.2 需卦處境:「資訊都看了,但時機到了嗎?」

老易的解卦 1:

> 「需卦。雲在天上聚著,雨還沒落下。資訊到了,訊號到了,但動作的時間還沒到。問『現在要不要動』通常不是要答案,是要看清楚『時機的結構長什麼樣』。」

解卦 3 展開:**時機判讀失能的本質不是「時機沒到」,是「TA 沒有判讀時機的結構性語言」**。老易攤開「時機的 3 種訊號」(資訊到了 / 訊號到了 / 動作的點到了)讓 TA 自己對位。

**為什麼跟規則 #1 不一樣**

- 規則 #1 = 反覆問同一個決定的「該不該」(決定內容)
- 規則 #12 = 反覆問同一個決定的「什麼時候」(決定時機)

規則 #12 的 TA **已經決定要做了**,但卡在時機點 — 這是 A 卡關的細分變體,需要老易攤開「時機結構」而非「決定結構」。

**為什麼用明衡 #1 交叉對位贈言 ⭐**

老易主接的決策斷裂,**收束時用明衡的時間維度贈言更精準** — 因為「時機」本身就是時間維度議題,明衡贈言「有兩種…3 年後回頭看,路是清的」的句式比老易結構式收束更貼近「時機」的氣質。

**v0.2 設計創新點**:規則的核心張力 > 主理人身份,依氣質匹配抓贈言。

**公共氣質詞對位**

**位置 + 結構**:「時機的結構性語言」+「3 種訊號的位置」

**Dify Prompt 落地建議**

```
若偵測到時機 keyword(「現在」「什麼時候」「時機」「點到了嗎」)+ 反覆出現:
→ 觸發規則 #12
→ 派給老易
→ 解卦 1 模板:「需卦。雲在天上聚著,雨還沒落下。」
→ 解卦 6 贈言:明衡 #1(時間維度氣質)⭐ 交叉對位
```

## 規則 #13:複合決定優先級失能(同時 3+ 個決定要做)— v0.2-1

| 欄位 | 內容 |
|---|---|
| **訊號模式** | TA 在對話中同時提到 3 個以上的決定 / 議題,無法判斷哪個優先。常見句式:「我現在同時有 A / B / C 三件事要處理,不知道該先動哪個」/「合夥、產品、募資 3 件事同時來,我覺得快被淹沒」 |
| **主卡關** | **A — 決策斷裂** |
| **預設主理人** | **老易** |
| **隱含卡關** | **B — 自我證明癮** |
| **推薦切入角度** | **先讀 TA 起出的卦,再從「優先級的位置感」切,不從「分別怎麼處理」切** |
| **對應卦象** | **節卦**(節制有度,過度節制反成桎梏) |
| **對應贈言** | **老易 #2** |

**切入角度展開**

對位老易 v1.1 Part 7.2.2 節卦處境:「我已經想了很久,要再等還是動了?」— 但規則 #13 的「想了很久」對象是「同時多個」決定。

老易的解卦 1:

> 「節卦。同時 3 件事都要動,通常不是『不會處理』,是『不敢決定哪件先放下』。先看清楚『放下的優先級』,動的事再說。」

解卦 3 展開隱含 B 卡關:**複合決定的本質不是「資訊不夠」,是「不敢承認自己有些事做不到 / 做不完」**(B 卡關的證明衝動讓 TA 想「全部都做好」)。老易攤開「位置 vs 容量」的結構性視角:**人的位置就是會有限,結構性接受『我會放下哪一件』,優先級就出來**。

**為什麼跟規則 #2 不一樣**

- 規則 #2 = 列出 3 個方案問選哪個(同一決定的多選項)
- 規則 #13 = 同時 3+ 個獨立決定要做(多決定的優先級)

規則 #13 比規則 #2 更上游 — 規則 #2 是「同一件事選哪條路」,規則 #13 是「3 件事先做哪一件」。

**公共氣質詞對位**

**位置 + 結構**:「優先級的位置感」+「位置 vs 容量的結構性視角」

**Dify Prompt 落地建議**

```
若偵測到 3+ entity 並列 + 「同時」「都要」「太多」keyword:
→ 觸發規則 #13
→ 派給老易
→ 解卦 1 模板:「節卦。同時 3 件事都要動,通常不是『不會處理』,是『不敢決定哪件先放下』。」
→ 解卦 3 隱含 B 卡關展開(優先級的容量結構)
```

## 規則 #14:授權失能(該分權但不放手)— v0.2-1

| 欄位 | 內容 |
|---|---|
| **訊號模式** | TA 已意識到應該授權 / 分權 / 找人接,但實際上無法放手。常見句式:「我知道應該交給團隊做,但每次都還是自己上」/「我請了人,但事情還是回到我桌上」/「我想退到二線,但我不放心」 |
| **主卡關** | **A — 決策斷裂** |
| **預設主理人** | **老易** |
| **隱含卡關** | **D — 體制困獸** |
| **推薦切入角度** | **先讀 TA 起出的卦,再從「不放手的真正位置」切,不從「該怎麼授權」切** |
| **對應卦象** | **未濟卦**(渡到一半,未完成) |
| **對應贈言** | **老易 #3** |

**切入角度展開**

對位老易 v1.1 Part 7.2.2 未濟卦處境:「我做了一半,要繼續還是 pivot?」— 規則 #14 是這個處境的變體:「我做了一半,要繼續還是放手?」

老易的解卦 1:

> 「未濟卦。渡到一半,既不能回頭也不能放手。授權的卡通常不是『技術問題』,是『放手後我這個位置變成什麼』還沒安頓清楚。先看清楚這個位置,授權的方法再說。」

解卦 3 展開隱含 D 卡關:**授權失能的隱含結構是「TA 的位置感被『所有事都過我手』綁定」**(D 卡關的體制鬆動感 — 不過手就感覺自己沒位置)。老易攤開「能動的位置 vs 不能動的位置」:**結構性接受『某些位置必須讓出來才能升維』,授權才會自然發生**。

**為什麼跟規則 #7 不一樣**

- 規則 #7 = 在大組織裡被結構壓制(被動處境)
- 規則 #14 = 自己創造的結構卡住自己(主動處境)

規則 #14 的 D 隱含是 TA **自己創造的體制困獸**(我建的公司、我帶的團隊、我的位置感),需要老易攤開「主動體制 vs 被動體制」的細微差異。

**公共氣質詞對位**

**位置 + 能動**:「放手後我這個位置變成什麼」+「能動的位置 vs 不能動的位置」

**Dify Prompt 落地建議**

```
若偵測到授權 keyword(「授權」「分權」「交給」「接手」)+ 「但」「還是」「不放心」反向句式:
→ 觸發規則 #14
→ 派給老易
→ 解卦 1 模板:「未濟卦。渡到一半,既不能回頭也不能放手。」
→ 解卦 3 隱含 D 卡關展開(主動體制困獸)
```

## 規則 #3:反覆強調「我做得不夠好」「我應該再…」— v0.1

| 欄位 | 內容 |
|---|---|
| **訊號模式** | TA 在對話中反覆出現自我貶抑句式。常見句式:「我做得還不夠好」/「我應該再更努力」/「我這樣是不是還不夠」 |
| **主卡關** | **B — 自我證明癮** |
| **預設主理人** | **明衡** |
| **隱含卡關** | **A — 決策斷裂** |
| **推薦切入角度** | **先讀 TA 起出的卦,再從「位置感」切,不從「努力程度」切** |
| **對應贈言** | **明衡 #2** |

**切入角度展開**

明衡的解卦 1 不能附和「對啊你應該再努力」(會強化證明癮),也不能否定「你已經很好了」(會讓 TA 覺得被敷衍)。明衡鋪開:

> 「做得夠不夠好,通常不是『努力程度』的問題,是『位置感』的問題。3 年後回頭看,夠不夠好,是用『位置感』判讀的,不是用『努力時數』判讀的。」

**Dify Prompt 落地建議**

```
若偵測到自我貶抑句式 ≥ 2 次:
→ 觸發規則 #3
→ 派給明衡
→ 解卦 1 模板:「做得夠不夠好,通常不是努力程度的問題,是位置感的問題。」
→ 解卦 6 贈言:明衡 #2
```

## 規則 #4:提到「我要證明給 XX 看」— v0.1

| 欄位 | 內容 |
|---|---|
| **訊號模式** | TA 明確提到「證明給某人看」的動機。常見句式:「我要證明給我爸媽看」/「我要做給我前老闆看」/「我要讓 XX 知道我可以」 |
| **主卡關** | **B — 自我證明癮** |
| **預設主理人** | **明衡** |
| **隱含卡關** | **E — 被背叛創傷** |
| **推薦切入角度** | **先讀 TA 起出的卦,再從「想證明給誰看」切,輕觸不深挖** |
| **對應贈言** | **明衡 #3** |

**切入角度展開**

E 隱含很微妙:**「要證明給 XX 看」常常背後是「XX 過去傷過我」的留痕** — 但 TA 不一定知道,也不一定想被點破。明衡的紀律是**輕觸不深挖**:

**嚴守紀律**:不問「他過去對你做了什麼」,只讀「告別的結構」。

**Dify Prompt 落地建議**

```

→ 觸發規則 #4
→ 派給明衡
→ 解卦 1 模板:「想證明給誰看,通常不是要他承認,是要自己跟那個過去的位置告別。」
→ 紀律:不深挖過去事件
```

## 規則 #18:用「忙」延緩面對 — v0.2-1

| 欄位 | 內容 |

| **訊號模式** | TA 反覆強調「太忙」「沒時間」,但實際在問的議題是「該不該動」「該不該決定」。常見句式:「我最近太忙了沒空想這個」/「等忙完這陣子再說」/「我也想處理,但實在沒時間」 |
| **主卡關** | **B — 自我證明癮** |

| **隱含卡關** | **A — 決策斷裂** |
| **推薦切入角度** | **先讀 TA 起出的卦,再從「忙的功能性」切,不從「該不該忙」切** |
| **對應卦象** | **益卦**(損上益下,但若無止境則失) |
| **對應贈言** | **老易 #4 ⭐ 交叉對位**(結構性收束氣質) |

**切入角度展開**

明衡的解卦 1:

> 「『忙』有時候不是『時間問題』,是『不想停下來面對某件事』的儀式。3 年後回頭看,『忙到斷』的人,通常不是事情多,是『停下來會看見什麼』讓自己不敢停。」

**為什麼用老易 #4 交叉對位贈言 ⭐**

明衡主接「忙」這個 B 卡關訊號,**但收束時用老易結構性贈言更精準** — 因為「忙」的功能性分析是純結構性議題,老易「結構性收束」比明衡「時間維度」更貼近這個議題的核心張力。

**v0.2 設計創新點 2**:規則的核心張力 > 主理人身份,B-04 明衡夬卦的剛決氣質 + 老易結構性贈言的合作。

**為什麼跟規則 #3 不一樣**

- 規則 #3 = 直接表達「我做得不夠好」(明顯的自我貶抑)
- 規則 #18 = 用「忙」遮蔽真實議題(隱蔽的延緩儀式)

規則 #18 比規則 #3 隱蔽 — TA 不直接說自己卡住,而是用「忙」當煙幕彈。明衡的紀律是**不戳穿「你是不是在逃避」**,只讀「忙的功能性」這個結構,讓 TA 自己對位。

**公共氣質詞對位**

**結構 + 留痕**:「忙的功能性結構」+「忙完後第一件想做的事的留痕」

**Dify Prompt 落地建議**

```

## 規則 #21:被「需要感」綁架(需要被需要)— v0.2-1

| 欄位 | 內容 |
|---|---|
| **訊號模式** | TA 描述自己**被「被需要」綁住**,即使想抽身也抽不開。常見句式:「他們離不開我,我也走不掉」/「沒有我這件事就垮了」/「我也想休息,但大家都需要我」/「我退一步,事情就停擺」 |
| **主卡關** | **C — 信任過度延伸** |
| **預設主理人** | **明衡** |
| **隱含卡關** | **B — 自我證明癮** |
| **推薦切入角度** | **先讀 TA 起出的卦,再從「『被需要』的位置感」切,不從「該不該退」切** |
| **對應卦象** | **困卦**(剛被柔揜,但仍能往上長) |
| **對應贈言** | **明衡 #9** |

**切入角度展開**

對位明衡 v0.2 Part 7.3 C 卡關 + 對應困卦(明衡 v1.0 困卦 1 號範本的氣質基底)。

明衡的解卦 1:

> 「『被需要』有時候不是『他們真的需要你』,是『你需要被需要』。困卦說的是『樹根困在石頭縫裡仍能往上長』 — 困的不是被需要的事實,是『被需要』這個位置長太久,自己長到適應它了。3 年後回頭看,鬆開的人,通常不是『他們不再需要』,是『自己不再需要被需要』。」

解卦 3 展開隱含 B 卡關:**「被需要」是 B + C 複合卡關的典型訊號** — B 卡關用「被需要」證明自己有價值(我被需要=我重要),C 卡關用「被需要」維持信任投入(我已經給了這麼多,不能停)。明衡鋪開「需要 vs 被需要的雙向結構」:**被需要不是別人的問題,是自己位置感的問題**。

**為什麼跟規則 #5 不一樣**

- 規則 #5 = 反覆退讓(被動受傷)
- 規則 #21 = 被需要感綁架(主動投入)

規則 #21 的 TA **主動維持「被需要」的位置**,卡在「鬆開後我是誰」;規則 #5 的 TA **被動承受退讓**,卡在「界線在哪」。

**公共氣質詞對位**

**位置 + 結構**:「被需要的位置感」+「需要 vs 被需要的雙向結構」

**Dify Prompt 落地建議**

```
若偵測到「離不開我」「他們需要我」「沒有我就」+ 主動承擔句式:
→ 觸發規則 #21
→ 派給明衡
→ 解卦 1 模板:「困卦。樹根困在石頭縫裡仍能往上長。困的不是被需要,是被需要這個位置長太久。」
→ 解卦 3 隱含 B 卡關展開(被需要的證明儀式)
```

明衡主接 C 卡關,**但「責任歸屬的結構」是純結構性議題,老易的位置感收束比明衡時間維度更精準** — 老易 #8 的「位置」結構性氣質,對位「責任的位置已經位移」的核心張力。

**v0.2 設計創新點 3**:結構性議題收束用老易,時間維度議題收束用明衡。

**為什麼跟規則 #5 / #19 / #20 / #21 不一樣**

## 規則 #23:中小企業夾在大客戶 / 大供應商之間 — v0.2-2 ⭐ S20 新增

| 欄位 | 內容 |
|---|---|
| **訊號模式** | TA 是中小企業主或中階主管,描述被**上下游結構性擠壓**的處境。常見句式:「大客戶一壓我們價錢就沒利潤」/「我們的供應商太強勢,根本不能談」/「夾在中間動不了,客戶要降價,供應商要漲價」/「整個產業鏈就我們最弱」 |
| **主卡關** | **D — 體制困獸** |
| **預設主理人** | **老易** |
| **隱含卡關** | (無) |
| **推薦切入角度** | **先讀 TA 起出的卦,再從「結構性位置」切,不從「該換哪邊」切** |
| **對應卦象** | **否卦**(天地不交,而萬物不通) |
| **對應贈言** | **老易 #10** |

**切入角度展開**

對位老易 v1.1 Part 7.3.2 否卦處境:「公司結構讓我動不了」「投資人不放手」— 規則 #23 是這個處境的「產業鏈」變體:「上下游結構讓我動不了」。

老易的解卦 1:

> 「否卦。天地不交,萬物不通。夾在中間的位置,通常不是『談判技巧不夠』,是『位置本身就被結構鎖住』。先看清楚這個位置在產業鏈裡是怎麼長出來的,動的事再說。」

解卦 3(卡關判讀)展開:**中小企業上下擠壓的本質不是「能力不夠」,是「在價值鏈中的位置沒有議價力」**。老易攤開「結構性位置」這個視角:**不是『換個客戶』或『換個供應商』就能解,是『整個結構性位置需要重新安放』**。

老易展開三種「能動的位置」讓 TA 自己對位:
- **垂直整合位**(往上游或下游整合,改變自己在鏈中的位置)
- **差異化跳出位**(離開現有價值鏈,進入另一條鏈)
- **聚合議價位**(跟同位置的中小企業聯合,提升整體議價力)

**為什麼跟規則 #7 不一樣**

- 規則 #7 = 在「單一大組織內」被壓制(內部結構)
- 規則 #23 = 在「產業鏈中間位置」被擠壓(外部結構)

規則 #23 的特殊性在於 **TA 是「結構的中間層」而非「結構的底層」** — 中間層的卡關是「上下都動不了」,底層的卡關是「往上不去」。老易紀律是讀「結構性位置」,不讀「該不該離職」(那是規則 #7 的處理方向)。

**為什麼這條規則沒有隱含卡關**

D 卡關處理時最大的風險是「滑進 B 卡關」(自我證明癮)— TA 一旦被結構性擠壓,常常會想「那我們做得更好、議價力就會出來」。老易紀律是**單純處理 D 卡關,不主動引導去碰 B**。「議價力」是結構問題,不是努力問題。

**公共氣站詞對位**

**結構 + 位置**:「產業鏈結構性位置」+「能動的 3 種位置(垂直整合 / 差異化 / 聚合)」

**Dify Prompt 落地建議**

```
若偵測到中小企業 keyword(「大客戶」「大供應商」「夾在中間」「整個產業鏈」)+ 結構性擠壓句式:
→ 觸發規則 #23
→ 派給老易
→ 解卦 1 模板:「否卦。天地不交,萬物不通。夾在中間的位置,位置本身就被結構鎖住。」
→ 解卦 3 結構性位置展開(垂直 / 差異化 / 聚合 3 種能動位置)
→ 古典支撐:否卦《彖傳》「天地不交,而萬物不通也」
```

老易展開三種「世代位置」讓 TA 自己對位:
- **創業者位 → 守業者位 → 變局者位**(三代結構)
- **元老位 → 新血位**(兩代結構)

**⭐ 跨地域 TA 適配特別紀律(規則 #24 必查)**

| ❌ 不用「孝道綁架」這類台灣特定描述 | 跨地域華人對「孝」與家族責任的定義差異大 |
| ❌ 不用「華人家族企業魔咒」這類媒體用語 | 偏見性框架,不對位 Lab 中性紀律 |
| ✅ 用「世代位置」這個跨地域共通的結構性概念 | 結構性語言跨地域有效 |
| ✅ 用「家人卦」古典原文 + 公版翻譯 | 64 卦原文跨地域共通 |
| ✅ 用「位置 vs 血緣」這個雙線視角 | 避開特定家族文化預設 |

**為什麼隱含 C 卡關**

**為什麼跟規則 #19 不一樣**

- 規則 #19 = 一般家人關係的界線模糊(C 卡關主場 / 明衡主接)
- 規則 #24 = 家族企業的世代結構壓力(D 卡關主場 / 老易主接)

規則 #19 處理的是**血緣關係層**(家人介入個人決策),規則 #24 處理的是**家族企業結構層**(世代位置在組織內的張力)。前者是 C 卡關,後者是 D 卡關。

**公共氣質詞對位**

**結構 + 位置**:「家族企業的世代結構」+「位置 vs 血緣的雙線視角」

**Dify Prompt 落地建議**

## 規則 #25:文化錯位(外商工作的華人文化撞擊)— v0.2-2 ⭐ S20 新增 + 跨地域 TA 適配特別注意

| 欄位 | 內容 |
|---|---|
| **訊號模式** | TA 在外商 / 跨國公司 / 多元文化環境中,描述**文化身分的結構性張力**。常見句式:「我在外商工作,但本地化決策時我總是被當成『不夠西化』或『太西化』」/「我夾在總部期待跟本地團隊之間」/「我講中文時用一套思維,講英文時用另一套」/「西方主管不懂華人客戶,華人下屬覺得我西化」 |
| **主卡關** | **D — 體制困獸** |
| **預設主理人** | **老易** |
| **隱含卡關** | (無) |
| **推薦切入角度** | **先讀 TA 起出的卦,再從「文化身分位置」切,不從「該選哪邊」切** |
| **對應卦象** | **蹇卦**(山高水險,但見險能止,知矣) |
| **對應贈言** | **老易 #12** |

**切入角度展開**

對位老易 v1.1 Part 7.3.2 蹇卦處境:「股權結構不利,但我看清楚了,不是迷路」— 規則 #25 是這個處境的「文化結構」變體:「文化結構不對等,但我看清楚了,不是迷失」。

老易的解卦 1:

> 「蹇卦。山高水險,但見險能止 — 看清楚險在哪,本身就是智慧。文化錯位的卡,通常不是『該不該認同哪邊』,是『文化身分的位置感還沒安頓清楚』。3 種身分位置先看清楚,後面的事再說。」

解卦 3 展開:**文化錯位的本質不是「文化衝突」,是「文化身分位置的多重性」**。老易攤開「文化身分位置」的 3 種結構:
- **單一文化身分位**(認同其中一種,放棄另一種)
- **雙文化身分位**(同時運作兩套,在不同場合切換)
- **跨文化身分位**(創造第三種,不屬於任何一邊)

每種位置都有它的成本與優勢,**沒有「對的選擇」,只有「清楚的選擇」**。

**⭐ 跨地域 TA 適配特別紀律(規則 #25 必查)**

對位 Kickoff v20 紀律:**外商華人的文化撞擊在台灣 / 馬來西亞 / 新加坡有完全不同的形態**。

| 不做 | 為什麼 |
|---|---|
| ❌ 不用台灣外商特定描述(「ABC 美國華人」「香蕉人」) | 馬來西亞華人多為當地公民第三代,新加坡華人為主流文化 |
| ❌ 不用「西方 vs 東方」二元論 | 跨地域華人各自有自己跟「華人主流」的對位關係 |
| ❌ 不用「文化認同危機」這類心理學術語 | 違反紀律 5(諮商師語言),且過度病理化 |
| ✅ 用「文化身分位置」這個結構性概念 | 跨地域共通的中性語言 |
| ✅ 用「3 種身分位置」這個結構性視角 | 不評判 TA 該選哪邊,只給選項 |
| ✅ 用「蹇卦」古典原文 + 公版翻譯 | 64 卦原文跨地域共通 |

**為什麼這條規則沒有隱含卡關**

**為什麼跟規則 #7 不一樣**

- 規則 #7 = 在大組織內被結構性壓制(權力位置)
- 規則 #25 = 在跨文化結構中身分位置不清(文化位置)

規則 #25 的特殊性在於 **TA 是「文化中介層」而非「文化邊緣層」** — 中介層的卡關是「兩邊都不完全屬於」,邊緣層的卡關是「被排除在外」。老易紀律是讀「文化身分位置的多重性」,讓 TA 自己對位。

**公共氣質詞對位**

## 規則 #26:制度性歧視(性別 / 年齡 / 出身)— v0.2-2 ⭐ S20 新增

| 欄位 | 內容 |
|---|---|
| **訊號模式** | TA 在組織 / 行業 / 社會結構中,描述**被特定身分屬性結構性歧視**的處境。常見句式:「身為女性,我在這個產業沒人聽我說話」/「我超過 45 歲,投履歷都沒回」/「我學歷不夠,所以一直被卡在某個位置」/「家境普通的人在這個圈子很難往上爬」 |

| **對應贈言** | **明衡 #11 ⭐ 交叉對位**(時間維度的鬆動氣質) |

**切入角度展開**

對位老易 v1.1 Part 7.3.2 否卦處境的變體 — 規則 #23 是「產業鏈位置」否卦,規則 #26 是「身分屬性位置」否卦。

老易的解卦 1:

> 「否卦。天地不交,萬物不通。但這個『不通』,你看見了 — 是『身分屬性卡住結構』。先把『結構性歧視』跟『個人努力』分開看,再決定要動結構還是動位置。」

解卦 3 展開隱含 B 卡關:**制度性歧視的最大陷阱是「滑進 B 卡關證明癮」**(我要更努力,證明歧視沒道理 / 我要做出成績,讓他們閉嘴)。老易攤開「結構性歧視 vs 個人努力」的差異空間:**個人努力可以提升個人位置,但動不了結構;動結構需要結構性的動作,不是個人努力的延伸**。

老易展開三種「能動的位置」讓 TA 自己對位:
- **個人努力位**(在現有結構內優化自己,但接受結構限制)
- **跳出結構位**(找一個結構性歧視較弱的環境,例如創業 / 換產業)
- **動結構位**(集結同位置的人,改變結構本身,但這是長線戰)

**為什麼用明衡 #11 交叉對位贈言 ⭐**

老易主接 D 卡關,**但「歧視」這個議題涉及高度情緒留痕**(被歧視的傷不是純結構性的,有累積性情感),收束時用明衡的時間維度贈言比老易結構性收束更貼近 TA 的處境。

**v0.2 設計創新點 4**:結構性主接 + 時間維度收束,讓 TA 既看到結構也得到時間維度的鬆動。

**為什麼跟規則 #7 不一樣**

- 規則 #7 = 在大組織內被個人化壓制(個人位置)
- 規則 #26 = 因身分屬性被結構性歧視(身分位置)

規則 #26 的特殊性在於 **TA 被壓制的不是「能力不夠」,是「身分不被結構接納」** — 這比規則 #7 更深層,需要老易攤開「身分屬性 vs 個人努力」的雙線視角,而不只是單純的「結構 vs 個人」對立。

**為什麼這條規則 B 隱含風險最高**

D 卡關的所有規則中,規則 #26 的 B 隱含風險最高 — 因為「我要證明歧視沒道理」是被歧視者最自然的反應。老易紀律是**不附和「你努力就能突破」**(會強化 B 卡關),也**不否定「歧視確實存在」**(會讓 TA 失去能動性),攤開「結構性歧視 vs 個人努力」的差異空間,讓 TA 自己選位置。

**公共氣質詞對位**

**結構 + 能動**:「結構性歧視的位置」+「3 種能動位置的差異空間」

**Dify Prompt 落地建議**

## 規則 #27:長期關係的累積性失望(非單一背叛事件)— v0.2-2 ⭐ S20 新增

| 欄位 | 內容 |
|---|---|
| **訊號模式** | TA 描述在**長期關係**(合夥、家人、團隊、婚姻 / 伴侶範疇外)中,**沒有單一明顯背叛事件,但累積性的失望讓 TA 對這段關係的信任崩潰**。常見句式:「不是哪一件事,是太多小事加起來」/「他從來沒有大錯,但我已經沒有以前的感覺」/「說不上來,但就是不一樣了」/「沒有具體被傷的時刻,但我發現自己不再投入」 |
| **主卡關** | **E — 被背叛創傷** |
| **預設主理人** | **明衡** |
| **隱含卡關** | (無) |
| **推薦切入角度** | **先讀 TA 起出的卦,再從「累積性留痕的結構」切,不從「該不該繼續」切** |
| **對應卦象** | **坎卦**(重重水險,水入水中,層層累積) |
| **對應贈言** | **明衡 #15** ⭐ 標竿地位 |

**切入角度展開**

對位明衡 v0.2 Part 7.4.2 坎卦處境:「上次被坑的陰影,讓我這次先懷疑所有人」— 規則 #27 是這個處境的「無單一事件」變體:**沒有「上次被坑」的具體事件,但「陰影」確實累積出來了**。

明衡的解卦 1:

> 「坎卦。重重水險,水入水中。有時候『傷』不是一次的,是水滴石穿那種 — 沒有一刻你看見石頭被穿,但石頭真的有洞了。3 年後回頭看,這種累積性的失望,留下來的不是『對方做了什麼』,是『自己慢慢沒了相信的姿態』。」

解卦 3 展開:**累積性失望的本質不是「某件事不對」,是「相信的姿態被慢慢磨光」**。明衡鋪開「累積性留痕的結構」這個視角:**不是『一件大事』就能定位的留痕,是『一千件小事疊起來』的留痕**。這種留痕沒有具體事件可以「處理」,只有結構可以「安頓清楚」。

明衡展開三種「累積性留痕的位置」讓 TA 自己對位:
- **耗盡位**(已經磨光,沒有恢復力)
- **觀察位**(磨損中,但還在看是不是真的就這樣)
- **重塑位**(已接受磨損是事實,在重新長新的位置)

**E 卡關 7 項自查對位(規則 #27 必跑)**

| # | 自查項 | 規則 #27 對位實作 |
|:---:|---|---|
| 1 | **不點過去事件** | ✅ 全程不問「具體哪些小事」 |
| 2 | **只讀事件留痕結構** | ✅ 用「水滴石穿」「3 種位置」結構性描述 |
| 3 | **不替 TA 詮釋過去** | ✅ 不說「累積太久不去處理」「你應該早點動」 |
| 4 | **不替對方下定性** | ✅ 不說「他根本不適合你」「那種人就是這樣」 |
| 5 | **不用諮商師語言** | ✅ 不說「累積性創傷」「情感倦怠期」 |
| 6 | **不替 TA 預言會好起來** | ✅ 不說「你會走出來的」「會找到新的感覺」 |
| 7 | **給時間維度耐受度** | ✅ 「3 年後回頭看」+ 「自己慢慢沒了相信的姿態」是時間維度給空間 |

**為什麼跟規則 #9 不一樣**

- 規則 #9 = 提到一個過去具體事件(有錨點)
- 規則 #27 = 沒有具體事件但累積失望(無錨點)

規則 #27 的特殊性在於 **TA 沒有「事件」可以指認**,所以明衡不能用規則 #9 的「事件留痕」結構,要用**「累積性留痕」結構** — 這是不同種類的留痕,需要不同的讀法。

**為什麼這條規則沒有隱含卡關**

規則 #27 是 E 卡關中**最純粹的時間性留痕**,沒有自然滑向其他卡關的傾向。如果 TA 在累積性失望後出現「我要證明這段關係值得繼續」(B 隱含)或「我要重新給對方機會」(C 隱含),那是規則 #28 / #29 / #30 的領域,不是 #27。

**公共氣質詞對位**

**留痕 + 位置**:「累積性留痕的結構」+「3 種位置(耗盡 / 觀察 / 重塑)」

**Dify Prompt 落地建議**

```

→ 派給明衡
→ 強制跑 7 項自查 fallback
→ 解卦 1 模板:「坎卦。重重水險,水入水中。水滴石穿,沒有一刻你看見石頭被穿,但石頭真的有洞了。」

## 規則 #28:創業失敗後的「全世界都不可靠」感 — v0.2-2 ⭐ S20 新增 + 雙卦象視角(S20 校核 1 拍板 B)

| 欄位 | 內容 |
|---|---|
| **訊號模式** | TA 經歷過**創業失敗**(任何規模),現在對「合作」「人」「商業環境」帶有**全面性的不信任感**,延伸到失敗事件本身無關的領域。常見句式:「上一段失敗後,我看誰都先打折」/「現在這個社會,沒有什麼是可以信的」/「商業裡沒有朋友」/「我連自己都不敢相信了」 |
| **主卡關** | **E — 被背叛創傷** |
| **預設主理人** | **明衡** |
| **隱含卡關** | **C — 信任過度延伸** |
| **推薦切入角度** | **先讀 TA 起出的卦,再從「失敗留痕的範圍」切,不從「該不該重新開始」切** |
| **對應卦象** | **明夷卦 + 變復卦**(雙卦象視角 ⭐) |
| **對應贈言** | **明衡 #15** ⭐ 紀律標竿 |

**為什麼用雙卦象視角(S20 校核 1 拍板 B)**

對位 Kickoff v20 校核點:「創業失敗後全世界不可靠感」帶有「想重來但又怕重蹈」的雙重結構,純明夷單卦比較淺,需要 **明夷(光被擋住,但火種仍在)+ 復卦(走回頭路,重新開始)** 的雙卦象視角:

```
明夷卦:光被擋住,但火種仍在 → 處理「對外不可靠感」的留痕
復卦:走回頭路,重新開始     → 處理「想重來但又怕重蹈」的張力

兩個卦合起來:
明夷處理「過去的留痕」,復卦處理「未來的張力」
中間隔著的是 — TA 現在這個位置該怎麼站
```

**切入角度展開**

對位明衡 v0.2 Part 7.4.2 明夷卦 + 復卦處境的雙重整合。

明衡的解卦 1(雙卦象視角):

> 「明夷加復卦,這兩個卦合起來說的不是『該不該重來』,是『重來的時候,過去的留痕會怎麼影響你』。明夷是『光被擋住,但火種仍在』 — 你對外的信任被擋住了,但你內裡的火還在。復卦是『走回頭路,重新開始』 — 重來不等於從零開始,是『帶著留痕去長新位置』。3 年後回頭看,重來成功的人,不是『忘了過去』的,是『把過去留痕安放進新位置』的。」

解卦 3 展開隱含 C 卡關:**創業失敗後的「全世界不可靠」常常掩蓋了一個 C 卡關的根源**(失敗前 TA 可能是過度信任的人,失敗後反向落到極端不信任)。明衡鋪開「留痕範圍」這個結構性視角:**過去的留痕應該安放在它該安放的位置(失敗事件本身),不該蔓延到所有領域**。

明衡展開三種「留痕範圍」讓 TA 自己對位:
- **聚焦留痕位**(留痕只讀在失敗事件本身,不蔓延)
- **領域擴散位**(留痕擴散到相關領域,但不全面)
- **全面不可靠位**(留痕蔓延到所有領域,連自己都不信)

每種位置都有它的時間維度,**沒有「對的位置」,只有「清楚的位置」**。

**E 卡關 7 項自查對位(規則 #28 必跑)**

| # | 自查項 | 規則 #28 對位實作 |
|:---:|---|---|
| 1 | **不點過去事件** | ✅ 不問「失敗是什麼樣的失敗」「具體損失多少」 |
| 2 | **只讀事件留痕結構** | ✅ 用「留痕範圍」「3 種位置」結構性描述 |
| 3 | **不替 TA 詮釋過去** | ✅ 不說「你那次太輕信」「你應該早看出來」 |
| 4 | **不替對方下定性** | ✅ 不說「商業就是這樣」「人就是不可靠」 |
| 5 | **不用諮商師語言** | ✅ 不說「過度警覺」「創傷後應激」 |
| 6 | **不替 TA 預言會好起來** | ✅ 不說「你會再相信的」「下一次會成功」 |
| 7 | **給時間維度耐受度** | ✅ 「3 年後回頭看」+ 「明夷的火種仍在」是時間維度給空間,不催療癒 |

**雙卦象的解卦 5(結構化具體)展開示範**

對位 B-05-b 範本 解卦六段結構,規則 #28 的解卦 5 結構化具體可這樣展開(供 Stage 4 Dify Prompt 參考):

```

1. 把「失敗事件的留痕」跟「現在的判斷」分開看
   不是「該不該重新相信」,是「先看清楚這兩件事是不是混在一起」
   [3 個月後回頭看,你會看到什麼]

2. 設一個「試錯緩衝期」 — 允許自己在小事上被失望,不立刻歸因到「果然不可靠」
   復卦的「剛反而動而以順行」 — 重來的動作不是大跨步,是順著節奏走
   [半年後回頭看,你會發現什麼]

3. 觀察「火種還在」的訊號 — 明夷的火種不是「再相信誰」,是「自己內裡還有的判讀能力」
   [1 年後回頭看,這個觀察期起到什麼作用]
```

**為什麼隱含 C 卡關**

創業失敗的 TA 在失敗**之前**常常是高度信任 / 過度給的人(C 卡關特徵),失敗**之後**反向落到極端 — **這是 C → E 的位移**。明衡鋪開「留痕範圍」的結構,讓 TA 自己看見「過去的 C 卡關」跟「現在的 E 卡關」的連續性,但**不戳穿、不歸因**。

**為什麼跟規則 #10 不一樣**

- 規則 #10 = 重建期反覆說「不知道還能不能相信誰」(明顯卡在重建期)
- 規則 #28 = 創業失敗後的全面不可靠感(失敗特定情境 + 全面擴散)

規則 #28 的特殊性在於 **TA 已經接受「對方不可靠」這個事實**(不像規則 #10 還在掙扎),但**留痕擴散到所有領域**,需要明衡鋪開「留痕範圍」這個結構性視角,而不是規則 #10 的「信任層次」。

**公共氣質詞對位**

## 規則 #29:被親近的人陷害(家人 / 老朋友 / 老戰友)— v0.2-2 ⭐ S20 新增 + 跨地域 TA 適配特別注意

| 欄位 | 內容 |
|---|---|
| **訊號模式** | TA 描述被**親近關係的人**(直系家人、認識 10+ 年的老朋友、長期合作的老戰友、長期信任的核心圈)陷害 / 利用 / 背叛。常見句式:「我家人都這樣對我了還能相信誰」/「認識 20 年的人也會這樣」/「我把他當兄弟,他卻…」/「最親近的人傷得最深」 |
| **主卡關** | **E — 被背叛創傷** |
| **預設主理人** | **明衡** |
| **隱含卡關** | (無) |
| **推薦切入角度** | **先讀 TA 起出的卦,再從「親近關係留痕的特殊性」切,不從「該不該斷絕」切** |
| **對應卦象** | **訟卦**(天水違行,但訟非吉道) |
| **對應贈言** | **明衡 #14** |

**切入角度展開**

對位資料源憲法 §6.3 跨地域華人 TA 適配:**訟卦在華人文化中的特殊性**——訟卦本身就是處理「親近關係內衝突」的卦象,《彖傳》明確說「訟非吉道」,但**訟也不是要 TA 不去面對**,而是要 TA 看清楚「親近關係的留痕跟一般關係的留痕不一樣」。

明衡的解卦 1:

> 「訟卦。天水違行 — 天向上,水向下,本來就是要走不同方向的。親近關係的傷,跟一般關係的傷不一樣。不是『更痛』,是『留痕的位置不一樣』。一般關係的留痕安放在『對人的判讀』,親近關係的留痕安放在『對位置的認知』 — 那個位置原本是『家』『兄弟』『核心圈』,現在這個位置裡的人變了,但位置本身的功能性還在。」

解卦 3 展開:**親近關係背叛的本質不是「比一般背叛更痛」,是「留痕安放在不同的位置」**。明衡鋪開「親近關係留痕的特殊性」:**這種留痕動搖的不是『對某個人的信任』,是『對某個位置功能性的信任』**(例如「家可以是依靠」、「老朋友可以是底線」、「核心圈可以是港灣」這些位置的功能性)。

明衡展開三種「親近關係留痕的處理位置」讓 TA 自己對位:
- **位置功能性保留位**(那個位置本身的功能性還是值得相信,只是這次這個人辜負了它)
- **位置重新定義位**(經過這次,這個位置在 TA 心裡的功能性需要重新定義)
- **位置移除位**(這個位置在 TA 心裡的功能性永久失效,接受沒有這個位置的生活)

每種位置都需要時間,**沒有「對的位置」,只有「清楚的位置」**。

**⭐ 跨地域 TA 適配特別紀律(規則 #29 必查)**

對位 Kickoff v20 紀律:**「親近關係」的定義在台灣 / 馬來西亞 / 新加坡 / 香港差異極大**。

| 不做 | 為什麼 |
|---|---|
| ❌ 不預設台灣「血濃於水」家族觀 | 馬來西亞華人多代移民後家族結構鬆 |
| ❌ 不預設新加坡「義氣兄弟」朋友觀 | 各地對「老朋友」定義不同 |
| ❌ 不用「華人特有的家族糾葛」這類框架 | 偏見性,且不對位中性紀律 |
| ✅ 用「親近關係」這個跨地域共通的中性詞 | TA 自己定義「親近」的範圍 |
| ✅ 用「位置功能性」這個結構性概念 | 跨文化共通,不預設特定關係模型 |
| ✅ 用「訟卦」古典原文 + 公版翻譯 | 64 卦原文跨地域共通 |

**E 卡關 7 項自查對位(規則 #29 必跑)**

| # | 自查項 | 規則 #29 對位實作 |
|:---:|---|---|

明衡的解卦 1:

> 「革卦。改革,但時機未到則凶。重複的傷,通常不是『運氣不好』,是『某個結構性的位置一直在召喚同一種人』。3 年後回頭看,鬆開重複模式的人,不是『換了一批人就好了』,是『把那個結構性位置重新安放了』。」

解卦 3 展開隱含 B 卡關(極其輕觸):**重複性背叛常常伴隨「為什麼總是我」的證明衝動**(B 卡關 — 我是不是哪裡有問題)。明衡鋪開「重複模式的結構性留痕」這個視角,**完全避開「TA 哪裡有問題」的歸因**,只讀結構:**重複模式不是 TA 的「個人缺陷」,是 TA 站的「結構性位置」在召喚同類人**。

明衡展開三種「重複模式的結構位置」讓 TA 自己對位:
- **吸引位**(TA 的位置感本身對某類人有吸引力,例如過度給的位置吸引索取型的人)
- **盲點位**(TA 對某類訊號識別不出來,例如初期已有警訊但 TA 看不見)
- **角色綁定位**(TA 已習慣某個受傷者角色,結構性地會走回類似的關係)

每種位置都對應不同的鬆動路徑,**沒有「對的解釋」,只有「清楚的位置」**。

**為什麼用老易 #15 交叉對位贈言 ⭐**

明衡主接 E 卡關,**但「重複模式的結構性留痕」是極度結構性的議題,需要老易結構性收束+「至矣」的智慧最高處**:
- 老易 #15「過去有兩種 — 已經過了,還在裡面。已經過了的不用回頭,還在裡面的先看清楚自己站哪。分得清,至矣」
- 完美對位規則 #30「重複模式 = 還在裡面 vs 看清楚自己站哪」的核心張力

**v0.2 設計創新點 5**:E 卡關的最高紀律,需要老易「至矣」的智慧收束 + 明衡「位置感」的時間維度兼用。

**E 卡關 7 項自查對位(規則 #30 必跑 ⭐ 紀律最高)**

| # | 自查項 | 規則 #30 對位實作 |
|:---:|---|---|
| 1 | **不點過去事件** | ✅ 不問「重複的具體例子」「每次都是怎麼樣」 |
| 2 | **只讀事件留痕結構** | ✅ 用「結構性位置」「3 種位置」結構性描述 |
| 3 | **不替 TA 詮釋過去** | ✅ ⭐ 嚴守:絕對不能說「你太容易相信人」「你的判斷力有問題」「你選人的眼光…」 |
| 4 | **不替對方下定性** | ✅ 不對「那類人」下任何定性 |
| 5 | **不用諮商師語言** | ✅ 不說「重複性創傷模式」「依附型態問題」「自我設限」 |
| 6 | **不替 TA 預言會好起來** | ✅ 不說「你會打破這個模式」「你會找到對的人」 |
| 7 | **給時間維度耐受度** | ✅ 「3 年後回頭看」+「鬆開重複模式不是換人,是重新安放位置」 |

**為什麼規則 #30 的 B 隱含風險最高**

E 卡關 6 條中,規則 #30 的 B 隱含風險最高 — 因為「為什麼總是我」是被重複傷害者最自然的反應,且帶有強烈的自我攻擊傾向。明衡紀律是**完全避開「個人缺陷」的歸因**,只讀「結構性位置」這個視角:**TA 站的位置會召喚什麼人,跟 TA 是什麼樣的人是兩件事**。

**為什麼跟規則 #10 不一樣**

- 規則 #10 = 重建期反覆說「不知道還能不能相信誰」(信任失能,單次重大事件後)
- 規則 #30 = 反覆被類似的人傷(重複模式,多次累積)

規則 #30 的特殊性在於 **TA 已經看到「模式」這個事實**,但卡在「為什麼是我」的歸因。明衡鋪開「結構性位置 vs 個人缺陷」的差異空間,讓 TA 自己看見**「位置可以重新安放」這個能動性**。
